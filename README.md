# abragmania.github.io

A one-page static portfolio linking to the live project sites. Published with GitHub Pages at https://abragmania.github.io/.

- `index.html` and `style.css`: the page. No build step, no framework, no JavaScript.
- `shots/`: card screenshots (four 1440x900 landscape, one portrait phone shot).
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

To preview, open `index.html` in a browser.
